1.1 Stable Diffusion 详解

AI动漫制作的基石工具

SD 是什么？

Stable Diffusion（稳定扩散）是一个开源的AI图像生成模型，由Stability AI公司开发。

简单说：你给它一段文字描述，它就能生成对应的图片。这个过程叫做文生图（Text-to-Image, T2I）。

类比理解

想象你请了一个画师，你告诉他"画一个蓝发少女站在夕阳下的海边"，他就画出来。SD就是这个画师——只不过它是AI，速度极快（几秒钟），而且可以无限次修改。

它是怎么工作的？

SD的核心原理叫扩散模型（Diffusion Model），分两个方向：

清晰图片
→ 加噪 →
纯噪声

↑ 这是"正向扩散"——训练时用，让模型学习噪声是怎么加的

纯噪声
→ 去噪 × 20~30步 →
清晰图片

↑ 这是"逆向扩散"——生成时用，模型学会了如何从噪声中还原图片

你的文字描述就像导航，告诉模型"往哪个方向去噪"——最终得到你想要的画面。

SD 在AI动漫中的作用

在AI动漫制作流程中，SD承担了所有静态图像生成的工作：

  • 角色立绘 — 生成角色的外观设计图
  • 场景背景 — 生成各种场景的背景图
  • 分镜画面 — 按分镜脚本逐镜头生成关键帧
  • 角色变体 — 同一角色的不同表情、姿态、服装
  • 风格统一 — 通过LoRA/Checkpoint控制全片画风
  • 动画基础帧 — 为视频生成提供起始画面

版本怎么选？

版本 分辨率 特点 动漫生态 推荐度
SD 1.5 512×512 最老版本，插件最多，资源最丰富 极丰富 入门可用
SDXL 1024×1024 质量显著提升，生态已成熟 丰富 推荐首选
SD 3.0/3.5 1024×1024 新架构，质量好但生态不成熟 较少 观望
Flux 可变 黑森林实验室出品，质量极高 快速增长中 进阶选择
版本选择建议

零基础入门 → SDXL

  • 质量够高，不需要像1.5那样大量后期修补
  • 动漫模型生态已经足够丰富（Animagine XL、Counterfeit XL等）
  • 社区教程和资源多，遇到问题容易找到答案

为什么不是1.5？ 虽然1.5插件最多，但画质明显落后，512分辨率太小，做动漫需要大量放大和修补，反而更麻烦。

为什么不是3.0/Flux？ 质量虽好，但动漫相关的LoRA、ControlNet适配等生态还不完善，做动漫时可选工具少。
